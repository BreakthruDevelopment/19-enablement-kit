# Web

This is the `web/` layer of the CLAUDE.md hierarchy. It applies when work is in `web/`
or below, on top of the root `CLAUDE.md`.

- JSP and servlets are the front of the estate. Do not replace them with another stack.
- A class that both serves a request and writes to the database is worth naming. Quote
  the method. Do not split it unless the task asks.
- Do not put a credential in a page, a descriptor or a comment.
