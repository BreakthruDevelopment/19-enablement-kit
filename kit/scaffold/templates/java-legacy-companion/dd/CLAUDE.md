# Deployment descriptors

This is the `dd/` layer of the CLAUDE.md hierarchy. It applies when work is in `dd/`
or below, on top of the root `CLAUDE.md`.

- A descriptor declares a transaction, a resource reference or a mapping. Name the
  bean it belongs to before changing it.
- Do not invent an element the server does not already use in this tree.
- When the descriptor and the class disagree, quote both. Do not silently pick one.
