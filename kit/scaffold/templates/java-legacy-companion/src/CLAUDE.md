# Java sources

This is the `src/` layer of the CLAUDE.md hierarchy. It applies when work is in `src/`
or below, on top of the root `CLAUDE.md`.

- Keep the package name the file already uses. Do not move a class to a new package.
- A class that looks up a resource should be quoted, not rewritten, unless the task
  says to change that lookup.
- Do not add a framework. The build is the one the repository already has.
