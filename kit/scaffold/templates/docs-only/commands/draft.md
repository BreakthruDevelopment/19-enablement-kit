# /draft

Draft $ARGUMENTS.

1. Read the documents that already cover the subject. Quote the lines you rely on.
2. Write the draft in the same terms those documents use.
3. If a fact is not in a document, mark it as not written down. Do not fill it in.
4. Do not edit until the draft is accepted when the change spans more than one file.
